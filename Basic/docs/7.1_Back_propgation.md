# Backpropagation

## What is Backpropagation?

### Intuition 💡

Imagine a student takes an exam and scores **60 marks**, but the target was **90 marks**.

The teacher checks the mistakes, gives feedback, and the student studies those weak areas to score better next time.

A neural network learns in the same way. It checks its mistakes and adjusts its weights to make better predictions.

---

## Definition

**Backpropagation** is the learning algorithm of a neural network. After the network makes a prediction, it compares the prediction with the correct answer, calculates the error (loss), sends that error backward through the network, and updates the weights so the next prediction is more accurate.

**In simple words:**

> **Backpropagation is the process of learning from mistakes by updating the weights to reduce prediction errors.**

---

## Steps

```text
Input
   ↓
Forward Propagation
   ↓
Prediction
   ↓
Calculate Loss
   ↓
Backpropagation
   ↓
Update Weights
   ↓
Better Prediction
```

---

## Example

Suppose a model predicts:

* **Actual Output = 1**
* **Predicted Output = 0.60**

Since the prediction is not correct, the model:

1. Calculates the error (Loss).
2. Sends the error backward through the network.
3. Updates the weights.
4. Makes a better prediction next time.

## Quick Revision

| Concept         | Summary                                   |
| --------------- | ----------------------------------------- |
| Backpropagation | Learns from mistakes by updating weights  |
| Purpose         | Reduce prediction error (loss)            |
| Direction       | Output Layer → Hidden Layer → Input Layer |
| Runs            | Only during training                      |
| Used With       | Gradient Descent                          |
| Goal            | Improve prediction accuracy               |
