# Activation Function

## What is an Activation Function?

### Intuition 💡

Imagine a teacher evaluating a student.

First, the teacher calculates the student's total score.

```text
Study Hours
Attendance
Assignments
        │
        ▼
   Overall Score = 82
```

Now the teacher decides:

```text
Pass or Fail?
```

This **decision-making step** is like an **Activation Function**.

Without an activation function, the neuron would only calculate a number but would never decide what that number means.

---

## Definition

An **Activation Function** is a mathematical function applied after the **weighted sum**. It decides what output the neuron should produce.

Flow:

```text
Input
   │
   ▼
Weighted Sum (z)
   │
   ▼
Activation Function
   │
   ▼
Neuron Output
```

---

## Why Do We Need an Activation Function?

### Intuition 💡

Imagine stacking **100 calculators**.

Each calculator can only perform addition and multiplication.

Even after 100 calculators, the result is still just another linear calculation.

Now replace each calculator with a **smart decision-maker**.

The network can now recognize faces, speech, handwriting, and other complex patterns.

That smart decision-maker is the **Activation Function**.

---

## Types of Activation Functions

| Activation Function | Output Range            | Mostly Used For                |
| ------------------- | ----------------------- | ------------------------------ |
| Step                | 0 or 1                  | Classical Perceptron           |
| Sigmoid             | 0 to 1                  | Binary Classification          |
| Tanh                | -1 to 1                 | Hidden Layers (older networks) |
| ReLU                | 0 to ∞                  | Hidden Layers (most common)    |
| Leaky ReLU          | Slightly negative to ∞  | Hidden Layers                  |
| Softmax             | Probabilities (sum = 1) | Multi-Class Classification     |
| Linear              | Any value               | Regression                     |

---

## Step Function

### Intuition 💡

Like an ON/OFF switch.

```text
z ≥ 0  → 1

z < 0  → 0
```

Used in the **Classical Perceptron**.

---

## Sigmoid Function

### Intuition 💡

Instead of saying:

```text
Pass
```

or

```text
Fail
```

it says:

```text
95% chance of Pass
```

Produces a probability between **0 and 1**.

Used in **Binary Classification**.

---

## ReLU (Rectified Linear Unit)

### Intuition 💡

Imagine a teacher saying:

> "Negative marks don't make sense."

So,

```text
-5 → 0

10 → 10
```

Formula:

[
\text{ReLU}(z)=\max(0,z)
]

Most widely used in **Hidden Layers**.

---

## Softmax

### Intuition 💡

Suppose an image could be:

* Cat
* Dog
* Horse

Softmax converts scores into probabilities.

Example:

```text
Cat   = 0.05

Dog   = 0.90

Horse = 0.05
```

Total Probability:

```text
1.00
```

Used in **Multi-Class Classification**.

---

## Linear Activation

### Intuition 💡

Sometimes we don't want to change the value.

Example:

```text
House Price = ₹45,20,000
```

Used in **Regression**.

# Weight

## What is a Weight?

### Intuition 💡

Imagine a teacher deciding whether a student will pass.

The teacher considers:

| Feature     | Importance |
| ----------- | ---------- |
| Study Hours | Very High  |
| Attendance  | Medium     |
| Sports      | Low        |

The **importance** given to each feature is called its **Weight**.

Example:

```text
Study Hours → Weight = 5

Attendance → Weight = 2

Sports → Weight = 0.3
```

Higher weight means the feature has more influence on the prediction.

---

## Definition

A **Weight** is a trainable parameter that represents the importance of an input feature.

Weights are automatically learned during training.

---

# Weighted Sum

## What is Weighted Sum?

### Intuition 💡

A teacher doesn't treat every subject equally.

Instead, each subject has different importance.

| Feature     | Value | Weight |
| ----------- | ----: | -----: |
| Study Hours |     8 |      5 |
| Attendance  |    90 |      2 |
| Assignments |     7 |      4 |

The teacher first multiplies each feature by its importance.

```text
(8 × 5)

+

(90 × 2)

+

(7 × 4)
```

This combined score is called the **Weighted Sum**.

---

## Formula

[
z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
]

Where:

* **x** = Input Features
* **w** = Weights
* **b** = Bias
* **z** = Weighted Sum (Linear Combination)

---

## Example

Given:

```text
Study Hours = 8

Attendance = 90

Assignments = 7
```

Weights:

```text
w₁ = 5

w₂ = 2

w₃ = 4

Bias = 10
```

Calculation:

```text
z = (8×5) + (90×2) + (7×4) + 10

  = 40 + 180 + 28 + 10

  = 258
```

This **258** is **not the final prediction**.

It is passed to an **Activation Function**, which produces the neuron's final output.

---

# Complete Flow of a Neuron

```text
Input Features
      │
      ▼
Multiply by Weights
      │
      ▼
Add Bias
      │
      ▼
Weighted Sum (z)
      │
      ▼
Activation Function
      │
      ▼
Neuron Output
```

# Quick Revision

| Concept             | One-Line Summary                                                       |
| ------------------- | ---------------------------------------------------------------------- |
| Activation Function | Converts the weighted sum into the neuron's output.                    |
| Weight              | Represents the importance of an input feature.                         |
| Weighted Sum        | Linear combination of inputs, weights, and bias ((z = w \cdot x + b)). |
| Step                | Outputs 0 or 1.                                                        |
| Sigmoid             | Outputs a probability between 0 and 1.                                 |
| ReLU                | Replaces negative values with 0.                                       |
| Softmax             | Converts scores into class probabilities.                              |
| Linear              | Keeps the value unchanged for regression.                              |
