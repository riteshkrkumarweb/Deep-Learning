##  Introduction

**LSTM (Long Short-Term Memory)** is a type of recurrent architecture
designed to overcome important limitations of standard **RNNs**,
especially the difficulty of preserving information over long sequences.

RNNs and LSTMs are important foundations for modern AI architectures and
developments such as:

-   Attention Mechanisms
-   Transformers
-   Large Language Models (LLMs)
-   ChatGPT


#  Why Do We Need RNNs?

## ANN and Independent Inputs

A traditional **Artificial Neural Network (ANN)** generally treats an
input as a collection of features.

For many problems, this is fine.

However, some data is **sequential**, meaning the order of the
information matters.

Examples:

-   Text
-   Audio
-   Time-series data

### Example

Consider:

> "Hi my name is Nitish"

The meaning depends partly on the order of the words.

If the complete sentence is treated simply as an unordered collection of
features, important relationships between earlier and later words can be
lost.

### Solution

**RNNs (Recurrent Neural Networks)** were introduced to process
sequential information while maintaining a **state** that carries
information from previous time steps.

------------------------------------------------------------------------

#  The Problem with Standard RNNs

An RNN passes information from one time step to the next.

For example:

``` text
t1 → t2 → t3 → t4 → t5 → ...
```

The hidden state carries information forward through the sequence.

This works well for relatively short dependencies.

### Short Sequence Example

Consider:

> "Maharashtra is ..."

An RNN can use the recent context to predict something such as:

> "Marathi"

The required information is relatively close to the prediction.

------------------------------------------------------------------------

## Long Sequence Problem

Now consider:

> "Maharashtra is a beautiful state. It has got 25 cities... Language
> spoken there is \_\_\_"

The information needed to predict the language appeared much earlier.

A standard RNN can struggle to preserve that early information across
many time steps.

------------------------------------------------------------------------

#  Vanishing and Exploding Gradient Problem

The major limitation discussed in the lecture is related to
**Backpropagation Through Time (BPTT)**.

During training, gradients are propagated backward through the sequence.

As the sequence becomes longer, the gradient can become extremely small
or extremely large.

These are known as:

-   **Vanishing Gradient Problem**
-   **Exploding Gradient Problem**

## Vanishing Gradient

When the gradient becomes very small while moving backward through many
time steps, the network has difficulty learning relationships involving
information from the distant past.

In simple terms:

``` text
Earlier information
       ↓
   t1 → t2 → t3 → t4 → t5 → ... → prediction
       ↓
Gradient becomes smaller
       ↓
Earlier information becomes difficult to learn
```

This is why a standard RNN can lose important long-term context.

------------------------------------------------------------------------

#  Core Idea of LSTM

**LSTMs were designed specifically to overcome the
vanishing-gradient-related long-term dependency problem in standard
RNNs.**

The key idea is to provide the network with a more effective way of
managing memory.

A useful way to understand this is through a story analogy.

------------------------------------------------------------------------

#  LSTM Story Analogy

Imagine reading a very long story and trying to remember only the
information that is important for understanding the complete story.

### Step 1 --- Important Background

> "1000 years ago in Pratapgarh state..."

The brain remembers important information such as:

-   1000 years ago
-   Pratapgarh

This information can remain useful for later parts of the story.

------------------------------------------------------------------------

### Step 2 --- Important Character

> "King Vikram was kind and powerful..."

The brain remembers:

-   Vikram
-   Vikram is the important character
-   Vikram is kind and powerful

------------------------------------------------------------------------

### Step 3 --- Old Information Becomes Irrelevant

> "XYZ king attacked and Vikram died..."

Now the previous information about Vikram being the current king may no
longer be useful.

The brain can remove or update that information.

------------------------------------------------------------------------

### Step 4 --- New Character

> "Vikram Junior became king..."

The memory is updated with the new important information:

-   Vikram Junior
-   New king

------------------------------------------------------------------------

### Step 5 --- Update Again

> "Vikram Junior died in battle..."

The information about Vikram Junior can now be removed or updated.

------------------------------------------------------------------------

### Step 6 --- New Important Event

> "Vikram Super Junior fought XYZ, won, and took revenge..."

The memory is updated again with the important information.

------------------------------------------------------------------------

### Final Question

> "How was the story?"

The brain can use the important information preserved throughout the
story to understand and classify the overall story.

The transcript uses this analogy to explain the central idea of LSTM:

> **Keep useful information, remove outdated information, and add new
> relevant information.**

#  Short-Term Memory vs Long-Term Memory

One of the major ideas in the lecture is the distinction between
**short-term memory** and **long-term memory**.

## Problem in Standard RNN

A standard RNN has a single state mechanism.

Because information is continuously passed through this state, recent
information can dominate and older information can be overwritten.

This makes it difficult to maintain useful information over long
sequences.

------------------------------------------------------------------------

# LSTM Uses Two Memory States

LSTM introduces two state variables:

  State   Meaning
  ------- ------------------------------------
  `Ct`    Cell State --- Long-Term Memory
  `ht`    Hidden State --- Short-Term Memory

### 1. Cell State --- `Ct`

The **Cell State** represents the long-term memory pathway.

It is designed to preserve relevant information over longer sequences.

Think of it as:

``` text
Long-Term Memory
       ↓
      Ct
```

### 2. Hidden State --- `ht`

The **Hidden State** represents the short-term/current context.

It is also used as the output of the LSTM cell at the current time step.

Think of it as:

``` text
Short-Term Memory
       ↓
      ht
```

------------------------------------------------------------------------

#  Example of Updating Memory

Consider:

> "Ankit is a great girl..."

The system may preserve information such as:

``` text
Ankit → Girl → She
```

Later, the sequence changes:

> "Nitish is a YouTuber..."

The relevant context changes.

The system can selectively remove outdated information related to Ankit
and update the memory with information related to Nitish.

The important idea is:

``` text
Old information
      ↓
 Decide what is no longer useful
      ↓
 Remove it

New information
      ↓
 Decide what is useful
      ↓
 Add it
```

This selective memory management is a core idea behind LSTM.

------------------------------------------------------------------------

#  RNN vs LSTM

## RNN

A standard RNN has:

``` text
One main state
```

This state carries information through the sequence.

## LSTM

An LSTM has:

``` text
Two state variables

Ct → Long-Term Memory
ht → Short-Term Memory
```

Therefore:

  -----------------------------------------------------------------------
  Feature                 RNN                     LSTM
  ----------------------- ----------------------- -----------------------
  Main state variables    1                       2

  Long-term memory        Limited                 Cell State `Ct`
  pathway                                         

  Short-term/current      Hidden State            Hidden State `ht`
  state                                           

  Information control     More limited            Uses gates

  Long-term dependencies  Can struggle            Designed to handle them
                                                  better
  -----------------------------------------------------------------------

------------------------------------------------------------------------

#  The Three Gates of LSTM

The LSTM controls information using **three gates**:

1.  **Forget Gate**
2.  **Input Gate**
3.  **Output Gate**

These gates decide what information should be removed, added, and
exposed as output.

------------------------------------------------------------------------

#  Forget Gate

### Purpose

The **Forget Gate** decides what information from the previous long-term
memory should be discarded.

It uses:

-   Current input `xt`
-   Previous hidden state `ht-1`

to determine what should be forgotten from:

``` text
Ct-1
```

### Simple idea

``` text
Previous Long-Term Memory
          ↓
     Forget Gate
          ↓
Remove outdated information
```

### Real-world analogy

Imagine cleaning your notebook before starting a new chapter.

You ask:

> "Which information from the previous chapter is no longer useful?"

The Forget Gate performs a similar role for the LSTM's memory.

------------------------------------------------------------------------

#  Input Gate

### Purpose

The **Input Gate** determines what new information should be added to
the long-term memory.

It considers:

-   Current input `xt`
-   Previous hidden state `ht-1`

and determines what relevant new information should be written into the
Cell State.

### Simple idea

``` text
Current Input + Previous Context
             ↓
         Input Gate
             ↓
     Select useful information
             ↓
       Add to Cell State
```

### Real-world analogy

While taking notes, you don't write down every word.

You select the important information and add it to your notes.

The Input Gate performs a similar selection process.

------------------------------------------------------------------------

#  Output Gate

### Purpose

The **Output Gate** determines what information from the updated memory
should be exposed as the current hidden state/output.

It uses:

-   Updated Cell State `Ct`
-   Current input `xt`
-   Previous hidden state `ht-1`

to produce:

``` text
ht
```

### Simple idea

``` text
Updated Long-Term Memory
          +
Current Context
          ↓
      Output Gate
          ↓
Current Hidden State
        ht
```

------------------------------------------------------------------------

#  Complete LSTM Mental Model

At each time step `t`, an LSTM receives three important inputs:

``` text
Ct-1
Previous Cell State
(Long-Term Memory)

ht-1
Previous Hidden State
(Short-Term Memory)

xt
Current Input
```

These are processed by the LSTM.

------------------------------------------------------------------------

## Step 1 --- Forget

The Forget Gate decides:

> What old information should I remove?

``` text
Ct-1
 ↓
Forget Gate
 ↓
Remove outdated information
```

------------------------------------------------------------------------

## Step 2 --- Add New Information

The Input Gate decides:

> What new information should I store?

``` text
xt + ht-1
      ↓
 Input Gate
      ↓
Useful new information
      ↓
Update Cell State
```

------------------------------------------------------------------------

## Step 3 --- Update Long-Term Memory

After forgetting outdated information and adding relevant information:

``` text
Ct-1
 ↓
Forget old information
 ↓
Add useful new information
 ↓
Ct
```

`Ct` is the **updated Cell State / Long-Term Memory**.

------------------------------------------------------------------------

## Step 4 --- Produce Current Output

The Output Gate decides what part of the updated memory should be
exposed as the current hidden state.

``` text
Updated Ct
    +
Current xt
    +
Previous ht-1
    ↓
Output Gate
    ↓
ht
```

`ht` becomes the **updated Hidden State / Short-Term Memory / Output**.

------------------------------------------------------------------------

# 16. Complete Flow

The overall idea can be visualized as:

``` text
                 Current Input
                      xt
                       │
                       ▼
              ┌─────────────────┐
              │   LSTM Cell     │
              │                 │
Ct-1 ────────►│  Forget Gate    │
              │                 │
ht-1 ────────►│  Input Gate     │
              │                 │
xt ──────────►│  Output Gate    │
              └─────────────────┘
                       │
              ┌────────┴────────┐
              ▼                 ▼
             Ct                ht
      Long-Term Memory    Short-Term Memory
                           / Current Output
```

#  Inputs and Outputs of an LSTM Cell

## Inputs

An LSTM cell receives:

### `Ct-1`

Previous Cell State.

Meaning:

> Previous long-term memory.

### `ht-1`

Previous Hidden State.

Meaning:

> Previous short-term/current context.

### `xt`

Current input at time step `t`.

Meaning:

> The information currently being processed.

------------------------------------------------------------------------

## Outputs

The LSTM produces:

### `Ct`

Updated Cell State.

Meaning:

> Updated long-term memory.

### `ht`

Updated Hidden State.

Meaning:

> Updated short-term memory and current output.

#  RNN vs LSTM --- Conceptual Summary

### Standard RNN

``` text
Input
  ↓
RNN State
  ↓
Next Time Step
  ↓
RNN State
  ↓
Next Time Step
```

The same basic state mechanism carries information forward.

The problem is that important information from far back in the sequence
can become difficult to preserve.

------------------------------------------------------------------------

### LSTM

``` text
              ┌──────── Cell State Ct ────────┐
              │                                │
              ▼                                │
Input xt → [ LSTM Cell ] → Updated Ct          │
              │                                │
              └──────────→ ht ────────────────┘
```

The LSTM provides a dedicated Cell State and uses gates to control
information flow.

#  Key Takeaways

1.  **Sequential data** depends on the order and context of information.
2.  **RNNs** were introduced to process sequential data using a
    recurrent state.
3.  Standard RNNs can struggle with **long-term dependencies**.
4.  One important reason is the **vanishing/exploding gradient problem**
    during BPTT.
5.  **LSTM** was designed to address the long-term dependency problem of
    standard RNNs.
6.  LSTM has two important states:
    -   `Ct` → Long-Term Memory / Cell State
    -   `ht` → Short-Term Memory / Hidden State
7.  LSTM uses three gates:
    -   Forget Gate
    -   Input Gate
    -   Output Gate
8.  The Forget Gate removes outdated information.
9.  The Input Gate adds relevant new information.
10. The Output Gate determines the current output/hidden state.
11. The central idea is **selective memory management**: preserve useful
    information, remove outdated information, and add relevant new
    information.
